# GLA: Grand Lap Australia

A browser platformer about Barry Lawson trying to get to work while everything in the outback gets in the way.

## Play

Open `index.html` locally, or visit the GitHub Pages site once publishing is enabled:

`https://djmadfella86.github.io/GLA_web_game/`

## Controls

- `A/D` or arrow keys to move
- `Space` or `W` to jump
- Jump again for Barry's double jump
- `R` to restart

## Notes

- The project is a static HTML/CSS/JS game.
- GitHub Pages can publish it directly from the repository root.
